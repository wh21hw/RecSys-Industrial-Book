## 📋 内容概览

全书共 37 章 + 前言，分为八大部分：

| 部分 | 章节 | 内容 |
|---|---|---|
| 第一部分 推荐系统基础 | 第 1~3 章 | 概览、架构、评价体系 |
| 第二部分 推荐系统模块 | 第 4~9 章 | 召回/过滤→粗排→精排→重排→混排→生成式推荐 |
| 第三部分 核心算法 | 第 10~13 章 | 召回模型、粗排模型、精排模型、重排混排模型 |
| 第四部分 工程实践 | 第 14~17 章 | 特征工程、离线服务、在线服务、向量检索 |
| 第五部分 进阶 | 第 18~27 章 | 兴趣建模、多目标、链路一致性、偏差、因果推荐等 |
| 第六部分 强化学习推荐 | 第 28~32 章 | 流量调控、多目标融合、Session决策、重排混排RL |
| 第七部分 多模态与生成式 | 第 33~34 章 | 多模态推荐、生成式召回与一体化排序 |
| 第八部分 前沿趋势 | 第 35~37 章 | 推荐大模型、LLM/Agent推荐、总结展望 |

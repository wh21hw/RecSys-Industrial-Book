时长预估

在短视频、直播等场景中，用户观看时长比点击行为更能反映真实满意度。时长预估（Watch Time Prediction）已成为现代推荐系统最核心的优化目标之一。本章将介绍工业界时长预估的常见建模方法。

21.1 时长预估的挑战

直接对播放时长进行回归建模面临以下问题：

  • 长尾分布：大量样本集中于短时长区间，少数样本时长极长
  • 行为噪声：相同内容在不同场景下观看时长波动大
  • 异常值敏感：MSE 损失对极端值敏感，训练不稳定
  • 收敛困难：回归任务通常比分类任务更难收敛

21.2 分类建模

将连续时长转换为分类问题是工业界最常用的做法。通过设定阈值，将观看行为离散化为二分类或多分类：

label = 1 if watch_time > threshold, else 0

常见阈值包括：3 秒（有效播放）、6 秒（深度播放）、完整播放（完播率）等。多分类则将时长划分为多个区间，如 [0-3s]、[3-10s]、[10-30s]、[30s+]。

21.3 回归建模

21.3.1 MSE 回归

直接使用 MSE 损失预测原始时长。简单但容易受异常值影响。

21.3.2 对数变换

对时长取对数后再回归，压缩长尾分布：

L = (log(ŷ + 1) - log(y + 1))²

21.3.3 Weighted MSE

对不同时长区间赋予不同权重，降低极端值影响。

21.4 混合建模

工业界通常采用分类 + 回归的混合方案：

  • 先预测是否为有效播放（分类）
  • 在有效播放条件下预测具体时长（回归）

这种两阶段方案结合了分类的稳定性和回归的精度。

21.5 时长偏差

时长预估存在多种偏差：

  • 时长偏差：长视频天然有更高观看时长，需按视频时长归一化
  • 位置偏差：靠前位置的内容天然有更高观看时长
  • 选择偏差：只有被点击的内容才有观看时长标签

工业界通常通过完播率（Finish Rate）、有效播放率（EVR）等归一化指标来缓解时长偏差。

21.6 本章小结

时长预估是短视频推荐的核心任务。直接回归面临长尾分布和噪声问题，工业界通常采用分类建模、对数回归或混合方案。时长偏差是需要重点处理的问题，通过完播率等归一化指标可以缓解。

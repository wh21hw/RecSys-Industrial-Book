Session 推荐与层次决策

Session 推荐关注用户在一次浏览会话中的整体体验。RL 能够建模 Session 内的序列依赖关系。

31.1 Session 推荐

用户在一次 Session 中的行为是序列依赖的：前几条内容的推荐质量会影响用户是否继续浏览。Session 推荐需要优化整个序列的累计收益，而非单条内容的即时效果。

31.2 Session RL

将 Session 建模为 MDP：状态为用户历史行为和当前 Session 信息，动作为推荐内容选择，Reward 为用户反馈（点击、时长、继续浏览等），转移为用户状态的动态变化。

31.3 RLUR

RLUR (Reinforcement Learning for User Retention) [1] 直接优化用户留存指标，通过长期 Reward 设计引导模型学习提升留存的推荐策略。

31.4 层次强化学习

层次强化学习（HRL）将推荐系统建模为多层次决策：高层策略决定 Session 级目标（如探索 vs 利用），低层策略根据高层目标执行具体推荐。HRL-Rec 和 HiFI 是典型方法。

31.5 本章小结

Session 推荐通过 MDP 建模和长期 Reward 设计优化整个浏览序列。层次强化学习实现多层次协同决策。RLUR 直接优化用户留存。

参考文献

[1] Chen et al. "RLUR: Reinforcement Learning for User Retention". 2023.

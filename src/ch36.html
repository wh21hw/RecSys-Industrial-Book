LLM 与 Agent 推荐

LLM 与 Agent 驱动的推荐是推荐系统领域最新的前沿方向。大语言模型的强大理解和推理能力为推荐系统带来了新的可能性。

36.1 LLM4Rec 概述

LLM4Rec [1] 探索将大语言模型直接应用于推荐任务。与传统推荐模型不同，LLM 能够理解用户自然语言描述、物品文本信息以及上下文环境，实现基于语义理解的推荐。

36.2 RecGPT

RecGPT [2] 将推荐系统建模为对话式推荐，用户可以通过自然语言与推荐系统交互，表达细粒度的偏好和需求。

36.3 TALLRec

TALLRec [3] 通过指令微调（Instruction Tuning）将 LLM 适配到推荐任务，在少量推荐数据上实现良好的推荐效果。

36.4 Agent4Rec

Agent4Rec [4] 将推荐系统建模为多 Agent 协作问题：不同的 Agent 负责不同的推荐子任务（如用户理解、候选生成、排序决策），通过 Agent 间的通信和协作完成推荐流程。

36.5 推荐调参 Agent

利用 LLM Agent 自动分析实验结果、生成新的排序策略、进行超参数调整和实验规划，实现推荐系统策略优化的自动化。

36.6 检索生成与 AI 搜索

检索增强生成（RAG）在推荐系统中的应用：通过检索相关物品信息增强 LLM 的推荐能力。AI 搜索将推荐与搜索融合，通过 LLM 理解用户意图并生成个性化搜索结果。

36.7 本章小结

LLM 与 Agent 推荐代表了推荐系统的最新前沿。RecGPT 实现对话式推荐，TALLRec 通过指令微调适配推荐任务，Agent4Rec 实现多 Agent 协作推荐。随着 LLM 能力的不断提升，LLM 驱动的推荐有望成为推荐系统的新范式。

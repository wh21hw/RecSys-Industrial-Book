第三部分 推荐系统核心算法 · 第 13 章

重排与混排模型

第 7 章和第 8 章分别介绍了重排模块和混排模块的系统架构与处理流程。本章将进一步深入这两个模块中涉及的核心模型与算法，包括序列生成模型、序列评估模型、多样性打散算法以及多业务融合排序模型等。

13.1 序列生成模型

13.1.1 贪心序列生成

最简单的序列生成方法是贪心策略：根据多目标融合分数对候选物品排序，直接生成推荐序列。这种方法计算高效，但容易陷入局部最优。工业界通常通过高斯采样来增加多样性：以人工设定的权重向量为均值，通过多元高斯分布采样生成多组不同的权重组合，每组权重生成一个候选序列，再由序列评估器选择最优序列。

13.1.2 Beam Search 序列生成

Beam Search 在每一步扩展时保留 Top-K 条候选路径（即"束宽"），并在搜索过程中对不合法序列进行剪枝。相比贪心策略，Beam Search 能够在更大的搜索空间中寻找近似最优序列。

在重排场景中，Beam Search 的每一步扩展不仅考虑单个物品的得分，还可以融入业务约束（如相同垂类内容不得连续出现、广告间隔约束等），通过约束驱动的剪枝策略提升搜索效率。

13.1.3 生成式重排网络 (GRN)

GRN（Generative Reranking Network）使用序列生成模型（如 Transformer Decoder）直接生成推荐序列。与两阶段"生成+评估"框架不同，GRN 将序列生成和评估统一在一个模型中，通过自回归方式逐步生成推荐序列。

GRN 的训练目标可以是：

  • 序列级奖励最大化：直接优化序列整体价值
  • 强化学习策略梯度：将序列生成建模为马尔可夫决策过程
  • 对比学习：通过正负序列对比学习排序偏好

13.2 序列评估模型

序列评估器负责对生成的候选序列进行整体价值打分，从中选择最优序列。常见的序列评估方法包括：

13.2.1 位置衰减加权

最简化的评估方式是将序列中每个物品的单点分数按位置衰减加权求和：

value = Σᵢ wᵢ · f(xᵢ),   wᵢ = 1/i 或 wᵢ = e^{-(i-1)}

13.2.2 曝光概率建模

更贴合产品逻辑的评估方式基于用户"是否继续下滑"的行为建模。设用户打开 App 的初始概率为 p₀，观看第 j 个视频后继续下滑的概率为 p_slide(xⱼ)，则第 i 个物品的曝光概率为：

p(itemᵢ) = p₀ · Πⱼ<ᵢ p_slide(xⱼ)

第 i 个物品的价值为 valueᵢ = p(itemᵢ) · f(xᵢ)，整个序列 L 的整体价值为 Σᵢ valueᵢ。

13.3 多样性打散算法

13.3.1 MMR (Maximal Marginal Relevance)

MMR 是信息检索领域经典的多样性排序算法。其核心思想是在每一步选择中，同时考虑候选物品与用户需求的相关性以及与已选物品的差异度：

MMR = argmax [λ · Sim₁(Dᵢ, Q) - (1-λ) · maxⱼ∈S Sim₂(Dᵢ, Dⱼ)]

其中 Sim₁ 衡量物品与用户的相关性，Sim₂ 衡量物品间的相似度，λ 控制相关性与多样性的平衡。

13.3.2 DPP (Determinantal Point Process)

DPP 源于量子力学中的费米子统计行为，通过行列式来度量集合的多样性。在推荐系统中，DPP 将物品的相关性分数和相似度矩阵组合为 Kernel 矩阵：

L = Diag(r) · S · Diag(r)

其中 r 为相关性分数向量，S 为物品间相似度矩阵。子集 Y 的多样性质量定义为 det(L_Y)，通过贪心算法进行近似求解，计算复杂度为 O(K²N)。

13.3.3 SSD (Sliding Spectrum Decomposition)

SSD 由小红书团队在 KDD 2021 提出。其核心创新是将用户完整的浏览序列纳入建模范围，通过高阶奇异值分解（HOSVD）对滑动窗口张量进行分解，度量整个序列的全局多样性。SSD 采用一步改进型 Gram-Schmidt 正交化（one-step MGS）实现高效推理，整体复杂度为 O(NTd)，显著优于 DPP 的 O(N²d)。

13.4 混排融合排序模型

13.4.1 分数校准

不同业务的价值分来源于各自模型的 pxtr 预估结果，天然存在高估或低估问题。混排前需要通过保序回归（Isotonic Regression）和贝叶斯平滑（Bayesian Smoothing）进行校准：

  • 保序回归：保证校准函数单调递增，使用 PAVA 算法修正违反单调性的分桶
  • 贝叶斯平滑：利用 Beta 先验分布对分桶 CTR 进行平滑，降低小样本统计噪声
  • 线性插值：消除分桶边界跳变，使校准曲线连续平滑

13.4.2 PID 流量调控

混排后处理阶段通常使用 PID 控制器进行实时流量 Load 调控：

u(t) = Kₚ · e(t) + Kᵢ · Σ e(τ) + K_d · de(t)/dt

其中 e(t) 为目标流量占比与实际流量占比的误差。PID 控制器通过比例项实现快速纠偏、积分项消除稳态误差、微分项抑制超调震荡，实现各业务流量的稳态收敛。

13.5 本章小结

本章系统介绍了重排与混排模块中的核心模型与算法。在序列生成方面，从贪心策略到 Beam Search 再到生成式重排网络，展示了序列生成能力的逐步提升。在序列评估方面，从位置衰减加权到曝光概率建模，体现了对用户真实行为模式的深入理解。在多样性打散方面，MMR、DPP 和 SSD 三种方法分别代表了不同层次的多样性建模能力。在混排融合方面，分数校准和 PID 流量调控构成了多业务协同的基础设施。

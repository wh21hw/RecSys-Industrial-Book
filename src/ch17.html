向量检索系统

向量检索（Vector Retrieval / ANN Search）是现代推荐系统召回层的核心基础设施。双塔模型、图神经网络、多兴趣模型等召回算法都需要将物品 Embedding 存储在向量索引中，在线阶段通过近似最近邻搜索（ANN）快速检索与用户向量最相似的物品。本章将系统介绍向量检索的核心算法与工程实践。

17.1 为什么需要 ANN

在推荐系统中，物品库规模通常达到数千万甚至数十亿级别。对于一次推荐请求，系统需要在毫秒级时间内从海量物品向量中找到与用户向量最相似的 Top-K 物品。

精确最近邻搜索（KNN）的计算复杂度为 O(N·d)，其中 N 为物品数量，d 为向量维度。当 N 达到亿级时，暴力搜索的延迟远超系统预算。因此，工业界采用近似最近邻搜索（Approximate Nearest Neighbor, ANN）算法，在牺牲少量精度的情况下大幅降低搜索延迟。

17.2 树基方法

17.2.1 KD-Tree

KD-Tree 是一种对 k 维空间进行划分的二叉树结构。每个内部节点选择一个维度进行分裂，将空间划分为两个半空间。KD-Tree 在低维空间（d < 20）中效率较高，但在高维空间中由于"维度灾难"效果急剧下降。

17.2.2 Annoy

Annoy（Approximate Nearest Neighbors Oh Yeah）是 Spotify 开源的向量检索库。其核心思想是通过随机超平面对空间进行二分划分，构建一棵森林（Ensemble of Trees）。每棵树通过随机选择两个点构造超平面进行分裂，直到每个叶子节点包含的向量数小于阈值。搜索时在所有树中并行查找候选叶子，再对候选集进行精确排序。

17.3 量化方法

17.3.1 乘积量化 (PQ)

乘积量化（Product Quantization）将 d 维向量切分为 m 个子向量，每个子向量独立进行 K-Means 聚类，得到 m 个码本（Codebook）。原始向量被压缩为 m 个聚类中心 ID 的组合，存储空间从 O(N·d) 降低到 O(N·m + m·k·d/m)。

搜索时，通过预计算查询向量到各码本中心的距离表，可以快速估算查询向量到任意物品向量的距离，计算复杂度从 O(d) 降低到 O(m)。

17.3.2 优化乘积量化 (OPQ)

OPQ（Optimized Product Quantization）在 PQ 基础上引入正交变换矩阵 R，对原始向量进行旋转后再进行量化，使得各子空间的方差分布更加均衡，从而提升量化质量。

17.4 图基方法

17.4.1 NSW (Navigable Small World)

NSW 构建一个可导航小世界图，每个节点与若干近邻节点相连。搜索时从任意节点出发，通过贪心导航逐步逼近查询点的最近邻。NSW 的搜索复杂度接近 O(log N)，但构建图索引的时间复杂度较高。

17.4.2 HNSW (Hierarchical NSW)

HNSW 是目前工业界最广泛使用的 ANN 算法之一。它在 NSW 基础上引入了层次结构：

  • 上层图：节点稀疏、连接长距离，用于快速定位目标区域
  • 下层图：节点密集、连接短距离，用于精确搜索

搜索时从最上层开始贪心导航，逐层下降直到最底层完成精确搜索。HNSW 的搜索复杂度为 O(log N)，在召回率和延迟方面均表现优异，是 Faiss、Milvus 等向量检索库的核心算法。

17.4.3 CAGRA

CAGRA（CUDA-Accelerated Graph Search）是 NVIDIA 提出的 GPU 加速图搜索算法，针对 GPU 并行计算特性进行了深度优化，在亿级向量库上实现了亚毫秒级搜索延迟。

17.5 倒排方法

17.5.1 IVF (Inverted File Index)

IVF 通过 K-Means 将向量空间划分为 K 个聚类（Voronoi Cell），每个聚类维护一个倒排链表。搜索时只扫描查询向量最近的 nprobe 个聚类，将搜索范围从 N 缩小到 N·nprobe/K。

17.5.2 IVF-PQ

IVF-PQ 将 IVF 和 PQ 结合：先用 IVF 进行粗粒度聚类筛选，再在候选聚类内使用 PQ 进行快速距离计算。这种组合在 Faiss 中被广泛使用，是亿级向量检索的标准方案。

17.5.3 IVF-HNSW

IVF-HNSW 用 HNSW 替代 K-Means 进行聚类中心查找，进一步提升 IVF 的搜索效率。Faiss 中的 IVF-HNSW 实现在大规模数据集上表现优异。

17.6 工业实践

17.6.1 Faiss

Faiss 是 Facebook 开源的向量检索库，支持 IVF、PQ、HNSW 等多种索引类型，以及它们的组合。Faiss 同时支持 CPU 和 GPU，是工业界使用最广泛的向量检索工具之一。

17.6.2 Milvus

Milvus 是 Zilliz 开源的云原生向量数据库，支持十亿级向量检索，提供完善的索引管理、数据增删改查以及分布式部署能力。

17.7 本章小结

本章系统介绍了推荐系统中的向量检索技术。树基方法（KD-Tree、Annoy）适合低维空间；量化方法（PQ、OPQ）通过压缩向量降低存储和计算成本；图基方法（HNSW）在召回率和延迟方面表现最优，是当前工业界的主流选择；倒排方法（IVF）通过聚类筛选缩小搜索范围。工业实践中通常采用 IVF-PQ 或 IVF-HNSW 等组合方案，在亿级向量库上实现毫秒级搜索。

精排模型

精排模型是推荐系统中算法迭代最频繁、模型复杂度最高、业务收益最直接的核心模块。与粗排阶段强调效率优先不同，精排阶段更加关注排序精度。工业界大量先进的用户兴趣建模、多任务学习、序列建模以及特征交叉网络，往往首先落地于精排模块。本章将系统介绍精排阶段的核心模型算法。

12.1 特征交叉网络

特征交叉（Feature Interaction）是精排模型最核心的能力之一。推荐系统的预测效果很大程度上取决于模型能否捕捉用户特征、物品特征以及上下文特征之间的高阶交互关系。

12.1.1 FM (Factorization Machine)

FM 由 Rendle [1] 于 2010 年提出，通过引入隐向量来建模二阶特征交叉。对于特征向量 x，FM 的预测公式为：

ŷ = w₀ + Σ wᵢxᵢ + Σᵢ<ⱼ ⟨vᵢ, vⱼ⟩xᵢxⱼ

其中 vᵢ 为特征 i 的隐向量，⟨vᵢ, vⱼ⟩ 表示两个隐向量的内积，用于刻画特征 i 和 j 的二阶交叉。FM 的核心优势在于通过隐向量分解，将二阶交叉参数从 O(n²) 降低到 O(nk)（k 为隐向量维度），使得高维稀疏特征场景下的二阶交叉变得可行。

12.1.2 DeepFM

DeepFM [2] 是工业界应用最广泛的精排模型之一。其核心思想是将 FM 与 DNN 进行联合训练，同时建模低阶和高阶特征交叉：

ŷ = sigmoid(y_FM + y_DNN)

FM 部分通过一阶和二阶特征交叉捕捉低阶交互关系，DNN 部分通过多层全连接网络捕捉高阶特征交叉。DeepFM 的优势在于两部分共享相同的 Embedding 层，无需人工特征工程即可自动学习低阶和高阶交叉，且两部分的梯度可以反向传播到共享 Embedding，实现联合优化。

12.1.3 DCN (Deep & Cross Network)

DCN [3] 提出了 Cross Network 来替代传统 DNN 进行高阶特征交叉。Cross Network 的核心操作为：

x_{l+1} = x₀ ⊙ (W_l · x_l + b_l) + x_l

其中 x₀ 为输入特征，x_l 为第 l 层的输出，W_l 和 b_l 为可学习参数。Cross Network 通过逐层交叉，能够自动学习任意阶数的特征交互。与 DNN 相比，Cross Network 的参数量更少，且每一层的输出都显式包含了 x₀ 的信息，避免了信息在深层网络中逐渐衰减的问题。

12.1.4 xDeepFM

xDeepFM [4] 将 DCN 的 Cross Network 改进为 Compressed Interaction Network（CIN），通过向量级联而非 Hadamard 积进行特征交叉，能够学习更高阶的特征交互。CIN 的每一层输出都是一个向量而非标量，因此表达能力更强。

12.2 用户兴趣建模

12.2.1 DIN (Deep Interest Network)

DIN [5] 由阿里巴巴提出，引入了目标级注意力机制，根据当前候选物品动态激活用户历史行为中的相关部分：

v_U = Σᵢ a(i) · eᵢ,   a(i) = MLP([eᵢ, e_a, eᵢ ⊙ e_a])

其中 eᵢ 为用户第 i 次行为物品的 Embedding，e_a 为候选物品 Embedding，a(i) 为注意力权重。DIN 的核心创新是：对于不同的候选物品，用户的历史行为会被赋予不同的权重，从而实现"因物而异"的兴趣表达。例如，当候选物品是运动鞋时，用户历史中的运动相关行为会获得更高权重；当候选物品是化妆品时，美妆相关行为会获得更高权重。

12.2.2 DIEN (Deep Interest Evolution Network)

DIEN [6] 在 DIN 基础上引入了兴趣演化层，建模用户兴趣随时间的动态变化。DIEN 采用 GRU 序列建模：

  • 行为序列层：将用户行为序列输入 GRU，提取行为之间的时序依赖
  • 兴趣抽取层：通过注意力机制从 GRU 隐藏状态中提取与当前候选相关的兴趣
  • 兴趣演化层：使用 AUGRU（Attention Update GRU）将注意力权重融入 GRU 更新过程，建模兴趣的演化轨迹

DIEN 还引入了辅助损失（Auxiliary Loss），利用真实点击行为监督兴趣提取过程，提升兴趣表示的准确性。

12.2.3 BST (Behavior Sequence Transformer)

BST [7] 使用 Transformer 的自注意力机制建模用户行为序列：

H = Transformer([e₁, e₂, ..., e_n] + PE)

相比 GRU，Transformer 能够建模序列中任意位置之间的依赖关系，不受距离限制。BST 在阿里巴巴的电商推荐场景中取得了显著效果提升，已成为工业界行为序列建模的主流方案。

12.3 多任务学习

12.3.1 Shared-Bottom

最简单的 MTL 架构：所有任务共享底层的表示网络，在顶层分别使用独立的任务塔输出不同目标的预估值。这种架构简单高效，但当任务差异较大时容易产生负迁移（Negative Transfer）。

12.3.2 MMoE (Multi-gate Mixture-of-Experts)

MMoE [8] 为每个任务引入独立的门控网络，从多个共享专家网络中动态选择：

y_t = Σᵢ g_t(i) · fᵢ(x),   g_t = softmax(W_t · x)

其中 fᵢ 为第 i 个专家网络，g_t 为任务 t 的门控权重。MMoE 通过软性路由机制让不同任务侧重不同专家，有效缓解负迁移问题。MMoE 已成为工业界多任务学习的基础架构。

12.3.3 PLE (Progressive Layered Extraction)

PLE [9] 将专家分为共享专家（Shared Experts）和任务专属专家（Task-specific Experts），通过多层路由实现更精细的参数共享控制。PLE 在腾讯视频推荐场景中取得了显著效果提升，已成为工业界 MTL 的主流方案之一。

12.3.4 ESMM (Entire Space Multi-Task Model)

ESMM [10] 由阿里巴巴提出，解决了 CVR 建模中的样本选择偏差（Sample Selection Bias）问题。传统 CVR 模型只在点击样本上训练，但推理时需要对全部曝光样本预测。ESMM 联合建模 CTR 和 CVR：

pCTCVR = pCTR × pCVR

模型在全部曝光样本上训练，通过 CTR 任务的监督信号间接学习 CVR，消除分布偏差。ESMM 的后续版本 ESMM2 [11] 进一步引入了点击后行为（如加购、收藏）的中间目标，构建了更细粒度的转化漏斗。

12.4 长序列建模

在短视频、电商等场景中，高活跃用户的历史行为序列可能长达数千甚至数万条。传统 Transformer 的自注意力机制计算复杂度为 O(n²)，难以处理长序列。工业界提出了多种长序列建模方案：

12.4.1 SIM (Search-based Interest Model)

SIM [12] 由阿里巴巴提出，采用两阶段策略处理长序列：

  • GSU (General Search Unit)：从长序列中通过简单规则（如类目匹配、Embedding 相似度）筛选出与当前候选物品相关的子序列
  • ESU (Exact Search Unit)：对筛选后的短序列使用 Transformer 进行精确建模

SIM 能够将用户行为序列从数千条压缩到数百条，在保持效果的同时大幅降低计算开销。SIM 的关键创新在于通过两阶段方案突破了长序列的计算瓶颈。

12.4.2 ETA (End-to-end Target Attention)

ETA [13] 使用局部敏感哈希（LSH）对行为序列进行降维和加速，避免了 SIM 中两阶段策略的信息损失。ETA 通过 SimHash 将行为 Embedding 压缩为二进制串，通过 Hamming 距离快速检索相关行为，实现端到端的长序列建模。

12.5 本章小结

本章系统介绍了精排阶段的核心模型算法。在特征交叉方面，从 FM 到 DeepFM 到 DCN 到 xDeepFM，展示了自动特征交叉能力的逐步提升。在用户兴趣建模方面，从 DIN 的目标级注意力到 DIEN 的兴趣演化再到 BST 的 Transformer 序列建模，体现了从静态到动态的演进。在多任务学习方面，从 Shared-Bottom 到 MMoE 到 PLE，展示了从硬共享到软路由的改进。ESMM 解决了 CVR 建模的样本选择偏差问题。SIM 和 ETA 突破了长序列计算瓶颈。精排模型的发展趋势是从简单到复杂、从单任务到多任务、从短序列到长序列、从静态建模到动态演化。

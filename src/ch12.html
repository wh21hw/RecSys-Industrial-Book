精排模型

精排模型是推荐系统中算法迭代最频繁、模型复杂度最高、业务收益最直接的核心模块。与粗排阶段强调效率优先不同，精排阶段更加关注排序精度。工业界大量先进的用户兴趣建模、多任务学习、序列建模以及特征交叉网络，往往首先落地于精排模块。本章将系统介绍精排阶段的核心模型算法。

12.1 特征交叉网络

特征交叉（Feature Interaction）是精排模型最核心的能力之一。推荐系统的预测效果很大程度上取决于模型能否捕捉用户特征、物品特征以及上下文特征之间的高阶交互关系。

12.1.1 DeepFM

DeepFM 是工业界应用最广泛的精排模型之一。其核心思想是将 FM（Factorization Machine）与 DNN 进行联合训练，同时建模低阶和高阶特征交叉：

ŷ = sigmoid(y_FM + y_DNN)

其中，FM 部分通过一阶和二阶特征交叉捕捉低阶交互关系：

y_FM = w₀ + Σ wᵢxᵢ + Σᵢ<ⱼ ⟨vᵢ, vⱼ⟩xᵢxⱼ

DNN 部分通过多层全连接网络捕捉高阶特征交叉：

y_DNN = MLP(x)

DeepFM 的优势在于两部分共享相同的 Embedding 层，无需人工特征工程即可自动学习低阶和高阶交叉，且两部分的梯度可以反向传播到共享 Embedding，实现联合优化。

12.1.2 DCN (Deep & Cross Network)

DCN 提出了 Cross Network 来替代传统 DNN 进行高阶特征交叉。Cross Network 的核心操作为：

x_{l+1} = x₀ ⊙ (W_l x_l + b_l) + x_l

其中 x₀ 为原始输入特征。Cross Network 的每一层都在原始特征的基础上进行交叉，因此能够有效建模高阶多项式特征交互。与 DNN 相比，Cross Network 的参数量更少，且每一层的输出都显式包含原始特征信息，避免了深层网络中信息丢失的问题。

12.1.3 xDeepFM

xDeepFM 将 DCN 的 Cross Network 扩展为 CIN（Compressed Interaction Network），通过向量级方式实现高阶特征交叉，同时保留了 FM 的二阶交叉能力和 DNN 的隐式高阶交叉能力。

12.2 用户兴趣建模

用户兴趣建模是精排模型的核心能力之一。在短视频、电商等场景中，用户的兴趣是动态变化的，且往往具有多峰分布特征。如何从用户历史行为序列中提取有效的兴趣表示，是精排模型优化的关键方向。

12.2.1 DIN (Deep Interest Network)

DIN 是阿里巴巴提出的经典用户兴趣建模方法。其核心创新在于引入目标级注意力机制（Target-aware Attention），根据当前候选物品动态激活用户历史行为中与之相关的部分：

v_U = Σ Attention(e_i, e_a) · e_i

其中 e_i 为用户历史行为物品的 Embedding，e_a 为当前候选物品的 Embedding。注意力权重由一个 MLP 计算得到：

Attention(e_i, e_a) = MLP([e_i; e_a; e_i - e_a; e_i ⊙ e_a])

DIN 的核心思想是：用户兴趣是多样的，对于不同的候选物品，应该关注用户历史行为中与之相关的部分。例如，当候选物品是一双球鞋时，应该更多关注用户历史浏览过的运动装备，而非美食或旅游内容。

12.2.2 DIEN (Deep Interest Evolution Network)

DIEN 在 DIN 的基础上进一步引入了兴趣演化建模。用户兴趣不仅多样，而且随时间演化。DIEN 通过 GRU（Gated Recurrent Unit）建模用户行为序列的时序关系，并引入 AUGRU（Attention Update GRU）机制，将注意力权重融入 GRU 的更新门，实现目标感知的兴趣演化建模。

DIEN 的核心架构包含三层：

  • Behavior Layer：通过 Embedding 将用户行为序列转换为向量序列
  • Interest Extractor Layer：使用 GRU 提取用户兴趣的时序表示
  • Interest Evolving Layer：使用 AUGRU 结合目标物品注意力，建模兴趣演化过程

12.2.3 BST (Behavior Sequence Transformer)

BST 使用 Transformer 替代 GRU 进行用户行为序列建模。相比 GRU，Transformer 的自注意力机制能够直接建模序列中任意两个位置之间的依赖关系，不受序列距离限制，因此更适合长行为序列场景。

BST 的核心结构为：

H = TransformerEncoder([e₁; e₂; ...; eₙ])

其中每个行为物品的输入表示由物品 Embedding、位置编码和上下文特征拼接而成。Transformer 的多头注意力机制能够从不同子空间捕捉用户兴趣的不同维度。

12.3 多任务学习模型

现代推荐系统通常需要同时预测点击率（CTR）、转化率（CVR）、观看时长（Watch Time）、点赞率（LTR）等多个目标。多任务学习（Multi-Task Learning, MTL）通过统一模型同时预测多个目标，能够实现参数共享和正则化效果。

12.3.1 Shared-Bottom

最基础的多任务学习架构为 Shared-Bottom，所有任务共享底层的特征表示网络，在顶层分别通过独立的 Tower 网络输出不同任务的预测值。其局限在于：当不同任务相关性较低时，共享底层网络会导致负迁移（Negative Transfer）问题。

12.3.2 MMoE (Multi-gate Mixture-of-Experts)

MMoE 引入了多门控混合专家机制，为每个任务设计独立的门控网络，动态选择不同 Expert 网络的输出组合：

y_t = Σ g_t(x) · f(x)

其中 g_t(x) 为任务 t 的门控网络输出，f(x) 为各 Expert 网络的输出。MMoE 能够根据任务关系自动学习参数共享程度，有效缓解负迁移问题。

12.3.3 PLE (Progressive Layered Extraction)

PLE 在 MMoE 基础上引入了层次化的 Expert 分离机制，将 Expert 分为任务专属 Expert 和共享 Expert 两类：

  • 任务专属 Expert：负责学习任务特定的特征表示
  • 共享 Expert：负责学习跨任务的通用特征表示

PLE 通过多层渐进式抽取，逐层提升特征表示的抽象层次，在任务差异较大时表现优于 MMoE。

12.3.4 ESMM (Entire Space Multi-Task Model)

ESMM 是阿里巴巴提出的针对 CVR 建模的多任务学习框架。其核心创新在于解决了 CVR 建模中的样本选择偏差（Sample Selection Bias）问题。传统 CVR 模型只在点击样本上训练，但在线推理时需要对所有曝光样本预测 CVR，导致训练分布与推理分布不一致。

ESMM 将 CTR 和 CVR 联合建模：

pCTCVR = pCTR × pCVR

模型在全部曝光样本上训练，通过 CTR 任务的监督信号间接学习 CVR，避免了样本选择偏差问题。

12.4 长序列建模

在短视频、电商等场景中，高活跃用户的历史行为序列可能长达数千甚至数万条。传统 Transformer 的自注意力机制计算复杂度为 O(n²)，难以处理长序列。工业界提出了多种长序列建模方案：

12.4.1 SIM (Search-based Interest Model)

SIM 采用两阶段策略处理长序列：

  • GSU (General Search Unit)：从长序列中通过简单规则（如类目匹配、Embedding 相似度）筛选出与当前候选物品相关的子序列
  • ESU (Exact Search Unit)：对筛选后的短序列使用 Transformer 进行精确建模

SIM 能够将用户行为序列从数千条压缩到数百条，在保持效果的同时大幅降低计算开销。

12.4.2 ETA (End-to-end Target Attention)

ETA 使用局部敏感哈希（LSH）对行为序列进行降维和加速，避免了 SIM 中两阶段策略的信息损失。

12.5 本章小结

本章系统介绍了精排阶段的核心模型算法。首先介绍了 DeepFM、DCN、xDeepFM 等特征交叉网络，它们通过不同方式建模低阶和高阶特征交互。随后深入讨论了 DIN、DIEN、BST 等用户兴趣建模方法，展示了从静态兴趣表示到动态兴趣演化建模的演进过程。接着介绍了 MMoE、PLE、ESMM 等多任务学习框架，分析了它们在解决负迁移和样本选择偏差方面的设计思路。最后介绍了 SIM、ETA 等长序列建模方法。精排模型的发展趋势是从简单到复杂、从单任务到多任务、从短序列到长序列、从静态建模到动态演化，其核心驱动力是工业界对排序精度和业务效果的持续追求。

时长预估

在短视频、直播等场景中，用户观看时长（Watch Time）比点击行为更能反映真实满意度。随着短视频平台的兴起，行业逐渐发现高 CTR 并不意味着用户真正喜欢内容——某些"标题党"内容虽然能够获得较高点击率，却无法带来持续观看行为。因此，时长预估（Watch Time Prediction, WTP）已成为现代推荐系统最核心的优化目标之一。本章将系统介绍工业界时长预估的建模方法、挑战和前沿进展。

21.1 时长预估的挑战

直接对播放时长进行回归建模面临以下核心挑战：

  • 长尾分布：大量样本集中于短时长区间，少数样本时长极长，分布严重偏斜。例如短视频场景中，大部分观看时长在 3-15 秒，但少数样本可能长达数分钟。这种长尾分布使得 MSE 损失被极端值主导，模型难以学习中等时长的精细差异。
  • 行为噪声：相同内容在不同曝光场景下观看时长波动大。用户可能在通勤时只看 5 秒，但在家中可能看完整条视频。这种上下文依赖性使得时长预估的不确定性很高。
  • 异常值敏感：MSE 损失对极端值敏感，少数超长时长样本可能主导梯度方向，导致训练不稳定。例如用户忘记关闭 App 导致视频自动播放数小时，这些异常样本会严重干扰模型训练。
  • 收敛困难：回归任务通常比分类任务更难收敛，需要更多训练轮次和更精细的学习率调整。
  • 值域范围广：观看时长的取值范围从 0 秒到数百秒甚至更长，不同量级的预测误差对用户体验的影响差异很大——3 秒和 5 秒的差异远大于 100 秒和 102 秒的差异。

21.2 分类建模

将连续时长转换为分类问题是工业界最常用的做法。通过设定阈值将观看行为离散化为二分类或多分类：

label = 1, if watch_time > threshold; 0, otherwise

常见阈值包括：

  • 3 秒（有效播放 EVR）：用户观看超过 3 秒通常被视为"有效曝光"，过滤了快速划过的无效曝光
  • 6 秒（深度播放）：用户观看超过 6 秒表明对内容有初步兴趣
  • 完整播放（完播率 FR）：观看时长达到或接近视频总时长，反映内容具有强吸引力

多分类则将时长划分为多个区间，如 [0-3s]、[3-10s]、[10-30s]、[30s+]，能够更细粒度地刻画用户满意度。分类建模的优势在于训练稳定、收敛快、对异常值鲁棒，且可以复用成熟的 CTR 预估模型架构。工业界通常将多个分类目标（如 EVR、FR）与 CTR 联合训练，形成多目标优化体系。

21.3 回归建模

21.3.1 MSE 回归

直接使用 MSE 损失预测原始时长：L = (ŷ - y)²。简单但容易受异常值影响，长尾分布下模型倾向于预测均值，难以捕捉个体差异。

21.3.2 对数变换

对时长取对数后再回归，压缩长尾分布：

L = (log(ŷ + 1) - log(y + 1))²

对数变换能够将长尾分布压缩到更均匀的区间，降低极端值的影响。例如原始时长 3 秒和 300 秒的差异为 297，取对数后差异仅为 log(301) - log(4) ≈ 4.3，大幅缩小。这使得模型对不同量级的时长给予更均衡的关注。

21.3.3 Weighted MSE

对不同时长区间赋予不同权重，降低极端值影响。例如对时长超过视频总长的样本（异常播放）降权，对短视频和长视频使用不同的权重方案。

21.3.4 Huber Loss

Huber Loss 结合了 MSE 和 MAE 的优点：在误差较小时使用 MSE（梯度方向明确），在误差较大时使用 MAE（对异常值鲁棒）：

L = 0.5·(ŷ-y)², if |ŷ-y| ≤ δ; δ·(|ŷ-y| - 0.5·δ), otherwise

其中 δ 为超参数，控制 MSE 和 MAE 的切换点。Huber Loss 在时长预估中比纯 MSE 更稳定。

21.4 混合建模

工业界通常采用分类+回归的混合方案：先预测是否为有效播放（分类），在有效播放条件下预测具体时长（回归）：

ŷ_watch = P(valid) × t_valid

其中 P(valid) 为有效播放概率，t_valid 为在有效播放条件下的时长预估值。这种两阶段方案结合了分类的稳定性和回归的精度：分类模型负责过滤无效曝光，回归模型在有效曝光范围内进行精细预估。

21.5 TPM：树型渐进回归

TPM（Tree-based Progressive Regression Model）[1] 由快手于 KDD 2023 提出，针对时长预估的四大特性设计了渐进式回归框架：

  • 序数性：观看时长虽然是连续值，但也具有序数性质——3 秒和 5 秒的差异在用户偏好上远小于 5 秒和 100 秒的差异。TPM 引入序数排名信息，使模型关注时长的相对排序而非绝对值。
  • 条件异方差性：不同特征空间下时长分布的方差不同。TPM 通过树结构划分特征空间，在不同叶子节点使用不同的回归头。
  • 多模态性：时长分布通常呈多模态（如快速划过的短时长峰值和完整观看的长时长峰值）。TPM 通过混合分布建模捕捉多模态特性。
  • 渐进性：时长预估应该从粗到细逐步精化。TPM 使用树结构实现渐进式预估：先判断大致时长区间，再在区间内精细回归。

TPM 在快手短视频推荐中取得了显著效果，相比传统 MSE 回归提升了视频消费时长。

21.6 GR-WTP：生成式回归

GR-WTP（Generative Regression Based Watch Time Prediction）[2] 于 2024 年提出，将时长预估重新建模为序列生成任务。与传统回归方法不同，GR-WTP 将连续时长离散化为 Token 序列，使用生成式模型（类似 LLM 的自回归架构）逐步生成时长预估结果。

GR-WTP 的核心创新在于：通过生成式建模，模型能够学习时长分布的复杂结构（如多模态、长尾），而非简单拟合均值。实验表明，GR-WTP 在处理宽值域和不平衡分布方面显著优于传统回归方法。

21.7 ProWTP：校准时长预估

ProWTP [3] 于 ICML 2025 提出，结合原型学习（Prototype Learning）和最优传输（Optimal Transport）进行时长回归预估。ProWTP 的核心思想是：通过学习一组"原型时长"（Prototype Watch Times），将回归问题转化为原型匹配问题，再通过最优传输方法校准预估结果。这种方法在处理可信度估计和不确定性建模方面具有优势。

21.8 时长偏差

时长预估存在多种偏差，需要在建模和评估时特别注意：

21.8.1 时长偏差

长视频天然有更高观看时长——一个 60 秒的视频即使被完整观看，其时长也远超一个 15 秒视频的完播。如果直接优化原始时长，模型会倾向于推荐长视频。工业界通常通过完播率（Finish Rate）来归一化：

FR = watch_time / video_duration

完播率消除了视频时长对预估的影响，使得不同时长的视频可以在同一尺度上比较。

21.8.2 位置偏差

靠前位置天然有更高观看时长——用户在浏览信息流时，对靠前内容的注意力更高。这种位置偏差需要在模型训练时通过位置特征或 IPS 加权进行纠偏。

21.8.3 选择偏差

只有被点击的内容才有观看时长标签，未被点击的内容没有时长反馈。这导致训练数据存在选择偏差（Selection Bias），模型只在"被点击的样本"上训练，但推理时需要对所有曝光样本预测。

21.9 工业实践建议

综合工业界的实践经验，时长预估的建模建议如下：

  • 起步阶段：使用分类建模（EVR + FR），与 CTR 联合训练，快速验证效果
  • 优化阶段：引入对数回归或 Huber Loss，在分类基础上增加回归头进行精细预估
  • 进阶阶段：尝试 TPM 或 GR-WTP 等前沿方法，利用序数性和渐进式建模提升效果
  • 评估阶段：同时监控原始时长、完播率、有效播放率等多个指标，避免单一指标的偏差

21.10 本章小结

时长预估是短视频推荐的核心任务。直接回归面临长尾分布、行为噪声和异常值敏感等挑战。工业界通常采用分类建模（EVR/FR）、对数回归或混合方案。TPM 通过树型渐进回归捕捉时长的序数性和多模态性，GR-WTP 将时长预估重新建模为序列生成任务，ProWTP 通过原型学习和最优传输进行校准。时长偏差（时长偏差、位置偏差、选择偏差）需要在建模和评估时特别注意。随着短视频推荐的发展，时长预估正在从简单的分类/回归向更精细的生成式和渐进式建模演进。

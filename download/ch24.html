第五部分 推荐系统进阶 · 第 24 章

多任务融合

第 5 章和第 6 章已经介绍了粗排和精排阶段的多目标融合方法。本章将进一步深入讨论多任务融合的理论基础、数学分析以及工业界的自动化融合方案。多任务融合（Multi-Task Fusion, MTF）是连接多任务学习模型输出与最终排序决策的关键桥梁——模型预估出 pCTR、pCVR、pWatchTime 等多个预估值后，如何将它们融合为一个统一的排序分数，直接决定了推荐效果。

24.1 融合公式分类

工业界常见的多目标融合方法可分为四大类：

表 24.1 多目标融合方法分类
类型代表方法优势劣势
基于值（Value-Based）线性加法、乘法公式直观、可解释对数值分布敏感
基于序（Rank-Based）倒数变换、幂次变换鲁棒性强丢失数值信息
值序融合（Hybrid）值×序加权兼顾数值与鲁棒性参数空间大
自动化融合（Auto）贝叶斯优化、CEM、RL无需人工调参搜索成本高

24.2 加法融合

加法融合（Additive Fusion）是最简单的融合方式，将多个预估值进行线性加权求和：

score = w1*p1 + w2*p2 + ... + wn*pn

其中 pi 为第 i 个目标的预估值（如 pCTR、pCVR 等），wi 为对应的权重。加法融合的核心特性是补偿性（Compensatory）：一个目标的高值可以补偿另一个目标的低值。例如，一个高 CTR 但低 CVR 的内容，与一个低 CTR 但高 CVR 的内容，可能获得相同的融合分数。

加法融合适用于目标之间相对独立的场景。其优点是直观可解释——权重 wi 直接反映目标 i 在融合中的重要性。缺点是对预估值的具体数值分布敏感：如果模型输出的 pCTR 整体偏高、pCVR 整体偏低，即使两者的相对排序正确，融合结果也会偏向 pCTR。

24.3 乘法融合

乘法融合（Multiplicative Fusion）将多个预估值进行乘法组合：

score = Product_i (bi + ai*pi)^gi

其中 ai、bi、gi 为可调超参数。乘法融合的核心特性是短板约束（Bottleneck-Constrained）：任何一个目标过低都会显著拉低最终得分。例如，如果 pCTR 接近 0，则整体得分接近 0，无论其他目标多高。

乘法融合更倾向于选择多个目标同时表现优秀的内容，而非在单一目标上极端突出的内容。在电商场景中，CTR 和 CVR 通常采用乘法组合，因为平台需要的是"既被点击又转化"的内容，而非"高点击低转化"或"低点击高转化"的内容。

24.4 加法 vs 乘法的数学分析

24.4.1 Taylor 展开分析

广义乘法公式 Score = Product_i (bi + ai*pi) 可通过 Taylor 展开揭示其与加法公式的关系：

Score = Const * [1 + Sum_i (ai*pi/bi) + Sum_{i

展开后可以看到：

  • 一阶项 Sum_i (ai*pi/bi) 对应线性加权求和——这就是加法融合
  • 二阶项 Sum_{i
  • 三阶项 对应三个目标同时优秀时的额外奖励
  • 更高阶项 对应更复杂的多目标协同关系

当偏置项 bi 很大时（bi >> ai*pi），高阶项可以忽略，乘法公式退化为加法公式。当 bi 很小时，高阶交互项占主导，模型更强调多目标协同。这意味着广义乘法公式实际上构造了一条从纯乘法到线性加法的连续过渡路径，bi 控制着过渡的位置。

24.4.2 梯度分析

从梯度视角可以更直观地理解两种融合方式的差异。对于乘法融合 Score = (b1 + a1*p1)(b2 + a2*p2)，对 p1 求偏导：

dScore/dp1 = a1 * (b2 + a2*p2)

即 p1 的重要性依赖于 p2 的大小——当 p2 较大时，p1 的提升价值更高。这体现了目标之间的正向协同（Positive Synergy）：一个目标越优秀，另一个目标的提升价值越高。

而对于加法融合 Score = w1*p1 + w2*p2，梯度为常数 dScore/dp1 = w1，各目标彼此独立，不存在协同效应。

24.4.3 幂指数 gamma 的影响

超参数 gamma 控制流量分布的陡峭程度。当 gamma > 1 时，高分样本进一步被放大，流量向头部内容集中（强化马太效应）。当 0 < gamma < 1 时，高分与低分之间的差距被压缩，流量分布更加平缓，中腰部内容获得更多曝光机会。

24.5 序变换函数

基于序的融合方法不直接使用预估值，而是利用排序位置进行融合。核心思想是：不同模型输出的预估值往往存在数值尺度不一致和分布漂移问题，而排序位置天然具有更强的鲁棒性。

常见序变换函数包括：

  • 倒数变换：S = 1/Rank，激进的头部强化策略，Top-1 和 Top-2 之间差异巨大
  • 平滑倒数：S = w/(Rank^lambda + b)，引入超参数 lambda 和偏置 b 控制曲线形状
  • 归一化幂次：S = w*(1 - (Rank/N)^lambda)，灵活控制资源在头部和中腰部的分配
  • 指数双曲：S = w*sinh(k*(2*Rank/N - 1))，在不同区间呈现不同敏感性

序变换的优势是对预估值的具体数值分布不敏感，但缺点是丢失了数值差异信息——排名第一和第二的物品可能分数极其接近（0.99 vs 0.98），也可能差异巨大（0.99 vs 0.50），但在序变换中都被视为相邻位置。

24.6 值序融合

值序融合（Hybrid Fusion）同时保留数值信息和序信息：

score = f(pxtr) * g(Rank_pxtr)

其中 f() 负责建模 Value 信息，g() 负责建模 Rank 信息。例如 f(pxtr) = log(1 + pxtr)，g(Rank) = 1/Rank^lambda。值序融合既保留了模型输出的细粒度数值差异，又获得了 Rank 融合的鲁棒性，目前大量工业级推荐系统都采用了某种形式的值序混合融合策略。

24.7 自动化融合

24.7.1 贝叶斯优化

贝叶斯优化使用高斯过程（GP）或 TPE 作为代理模型，通过采集函数（EI、UCB 等）指导参数搜索。适合低维参数空间（<20 维）。贝叶斯优化的核心优势是样本效率高——用尽可能少的实验次数找到尽可能优的参数。工业界广泛使用的超参数优化框架 Optuna 默认采用 TPE 算法。

24.7.2 CEM (Cross-Entropy Method)

CEM 通过维护参数分布并迭代更新，逐步向高收益区域收敛。每轮采样多组参数，在线上分配流量实验，根据收益筛选精英样本（Elite Samples），用精英样本重新拟合采样分布。CEM 的理论基础是最小化 KL 散度，适合中等维度参数空间（20-50 维）。快手 [1] 在多目标排序中广泛使用了 CEM 进行自动调参。

24.7.3 强化学习融合

将参数选择建模为序列决策问题，通过 RL 策略学习最优融合方案。RL 的优势在于能够优化长期收益而非即时效果，但面临训练不稳定和线上探索风险等挑战。近年来，一些公司开始尝试利用 LLM Agent 自动分析实验结果、生成新的排序策略。

24.8 工业实践

在工业实践中，多任务融合通常采用以下流程：

  1. 离线搜索：使用贝叶斯优化或 CEM 在离线数据上搜索初始参数
  2. 线上小流量验证：将搜索到的参数在小流量（5%-10%）上验证
  3. 逐步扩量：如果小流量效果正向，逐步扩大到 20%→50%→100%
  4. 持续监控：监控各业务指标，如果效果下降则回滚
  5. 周期更新：定期重新搜索参数，适应用户兴趣和业务目标的变化

快手 [1] 在多目标排序实践中开发了多种超参优化方法，包括 CEM、进化策略（ES）和贝叶斯优化。阿里巴巴飞猪 [2] 也采用了类似的自动化调参方案。

24.9 本章小结

加法融合是补偿型机制，乘法融合是协同增强型机制。广义乘法公式通过 Taylor 展开揭示了从线性加法到高阶交互的连续过渡——一阶项是加法，二阶及以上项是协同交互。自动化融合方法（贝叶斯优化、CEM、RL）正在替代人工调参，成为工业界的主流方案。工业实践通常采用"离线搜索→小流量验证→逐步扩量→持续监控→周期更新"的闭环流程。
